--COMO PREPARAR EL ENTORNO PARA EL FUNCIONAMIENTO DE LA APP--
1. Descargar Docker Desktop
2. Cambiamos la ip en 'api/.env' a la nuestra
3. En la terminal de VSC lanzamos 'pip install sqlalchemy'
4. En la terminal de VSC (estando dentro del directo api/) lanzamos 'docker-compose up -d'


--COMO ENTRAR AL SERVIDOR EC2 DE AWS--
1. Entramos a la terminal de powershell
2. Vamos a la carpeta donde esta el archivo .pem
3. Ejecutamos el comando: ssh -i "par_claves_servidor.pem" ubuntu@ec2-13-63-131-129.eu-north-1.compute.amazonaws.com
4. Una vez dentro, ejecutamos los comandos para poner en funcionamiento la app:
    - Despues de haber bajado las actualizaciones con github lanzamos:
        cd api/
    - Para iniciar:
        docker-compose up -d --build
    - Para detener:
        docker-compose down
    - Para forzar el reinicio:
        docker-compose up -d --build --force-recreate
